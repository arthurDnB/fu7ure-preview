Preview policy.

This site is a storefront prototype. Use sample details throughout.

Products and orders

The catalog contains concept products and sample specifications, stock, measurements and AUD prices. The shipping rates, delivery estimates and 30-day exchange window are for testing. Demo orders use simulated payment and tracking.

Data on this browser

The prototype stores your bag, demo order summaries and a waitlist signup status on this device. It keeps the email address, shipping details and support message in memory while you use each form. Sample messages and emails are for the walkthrough only.

Clear this site’s browser storage to remove the saved demo records. The host may process routine web requests as described in the GitHub privacy statement.
